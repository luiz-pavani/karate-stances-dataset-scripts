# Kinematic time-series — per-trial raw export

189 CSV files (180 dynamic + 9 STATIC) of pure per-frame kinematic
signals extracted from the Theia3D markerless reconstruction. No
aggregated descriptors, no demographic metadata.

Generated by `python -m kds.export_timeseries` from the **raw** Theia3D
output (`*_pose_0.c3d`); no additional filtering was applied beyond
whatever Theia3D performs natively prior to the raw export.

## Layout

```
timeseries_raw/
├── <ID>_<BASE>_T<N>_kinematics.csv     dynamic trials (180 files)
│       ID = ID003 … ID014
│       BASE = ZEN | KOK | KIB
│       N = 1 … 5
└── static/
    └── <ID>_STATIC_T1_kinematics.csv   STATIC references (9 files,
                                        ID006…ID014 only)
```

The `ID009/KUK/` source-folder typo is resolved at load time and
the corresponding files are written as `ID009_KOK_T<N>_kinematics.csv`.

## Schema

Each CSV has **98 columns**. Dynamic trials carry **1620 rows** (9.00 s
at 180 Hz); STATIC trials carry a variable number of rows (~360–1800).

| Column(s) | Content | Unit |
|---|---|---|
| `frame` | sample index 0 … n_frames−1 | — |
| `time_s` | time since trial start | s |
| **Linear position of 19 segment origins** (57 cols) | | |
| `<segment>_x` `<segment>_y` `<segment>_z` | origin of each segment in the laboratory frame | m |
| **Whole-body centre of mass** (3 cols) | | |
| `com_x` `com_y` `com_z` | mass-percentage-weighted sum of segment COMs; sex-specific inertia (M/F looked up internally; not written here) | m |
| **Joint angles** (12 joints × 3 axes = 36 cols) | | |
| `<joint>_flx_deg` `<joint>_abd_deg` `<joint>_rot_deg` | Cardan/Euler angles per ISB convention (Wu et al. 2002 / 2005); axes correspond to flexion/extension, abduction/adduction, internal/external rotation | deg |

### 19 segments (in column order)

`worldbody`, `pelvis`, `l_thigh`, `l_shank`, `l_foot`, `l_toes`,
`r_thigh`, `r_shank`, `r_foot`, `r_toes`,
`head`, `torso`,
`l_uarm`, `l_larm`, `l_hand`, `r_uarm`, `r_larm`, `r_hand`,
`pelvis_shifted`.

### 12 joints (in column order)

Lower limb (Z-X-Y Cardan sequence): `hip_right`, `hip_left`,
`knee_right`, `knee_left`, `ankle_right`, `ankle_left`.
Upper limb (Y-X-Z Cardan sequence): `shoulder_right`, `shoulder_left`,
`elbow_right`, `elbow_left`.
Axial (Z-X-Y Cardan sequence): `pelvis_world`, `trunk`.

## What is *not* in these CSVs

- No demographic metadata (sex, age, height, mass, style, modality,
  grade, etc.). The sex required for the COM inertia is looked up
  internally and used only to choose the inertia table.
- No aggregated descriptors (means, ROMs, RMS, path lengths). For those,
  see `data/processed_summary/`.
- No force-platform data. Kinetics will be added in a future release.

## Coordinate frame

The laboratory frame is the one set by the Qualisys system at the time of
acquisition: X mediolateral, Y anteroposterior, Z vertical (upward
positive). Units are SI (m, s, deg).

## Regeneration

```bash
python -m kds.export_timeseries \
    --data-root "/path/to/Kinematic Data" \
    --output-dir ./data/timeseries_raw
```

Add `--filtered` to read the Theia-filtered C3D variant instead of the
raw one.
